Конструктор отчетов

Локальный MVP-редактор схемы отчёта для HubCloud. Источник истины: report.schema.json.

Editor

Базовые поля схемы

Ветки datasource

Ветки выбирают фактический query по параметрам тестового запуска. Если ни одно условие не подошло, используется ветка else.

Runtime вызов DS

Техническое описание тестового POST-запроса хранится в schema.datasources.main.runtime. Токен сюда не сохраняем.

Datasource parameters

Эти параметры сохраняются в JSON схемы и используются для body тестового вызова и placeholder-подстановки в query.

Тестовое подключение

Эти данные нужны только для проверки источника и не попадают в JSON схемы.

Тестовый запрос пока не собран.
Поля источника данных

Описание результата DS хранится в schema.datasources.main.resultSchema.

Фильтры

Список фильтров хранится в schema.filters и сразу меняет preview.

Вкладки

Вкладки хранятся в schema.tabs и управляют кнопками представлений.

Таблицы

Таблицы хранятся в schema.tables; вкладки выбирают их через tableRef.

План данных

Проверка связей: какие таблицы используют какие datasource, сколько веток и mock-строк есть у каждого источника.

Колонки таблицы

Колонки редактируются для выбранной таблицы и сразу перестраивают preview.

Итоговые карточки

Карточки хранятся в schema.summaryCards и считаются по mock-строкам.
